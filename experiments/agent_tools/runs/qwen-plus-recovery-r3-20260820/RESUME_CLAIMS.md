# 简历表述候选

- 构建覆盖拟合、状态查询、任务取消、无需调用及失败修复的 10 例物理实验 Tool-Agent 评测集。
- 设计 `schema_only`、`skill_feedback`、`guided_repair` 三组消融策略，并实现逐案例原始轨迹、Bootstrap 置信区间和自动化指标图表。
- 在 `qwen-plus` 上，引入 Skill 与结构化执行反馈后，端到端成功率由 16.7% 提升至 96.7%（+80.0 个百分点），Recovery@1 由 16.7% 提升至 96.7%（+80.0 个百分点）。
- 显式 repair 提示相对 `skill_feedback` 未产生可测增益（端到端 +0.0 个百分点）；该结果按“当前样本出现性能天花板”解释，不夸大为普遍结论。

注意：这些数字只对应 Run `qwen-plus-recovery-r3-20260820`，不可改写为大规模或跨模型结论。
