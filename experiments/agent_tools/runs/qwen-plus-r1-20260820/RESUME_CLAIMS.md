- 设计 `schema_only`、`skill_feedback`、`guided_repair` 三组消融策略，并实现逐案例原始轨迹、Bootstrap 置信区间和自动化指标图表。

注意：这些数字只对应 Run `qwen-plus-r1-20260820`，不可改写为大规模或跨模型结论。
